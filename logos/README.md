# Official logos

## Primary logo

[`pandalogica-logo.png`](pandalogica-logo.png) is the owner-supplied PandaLogica logo, 1024 × 1024 pixels in RGBA PNG format. It has a white background and is intended for use where that background fits the design. Keep its proportions intact; avoid cropping, recoloring, stretching, or placing text over it.

Use the file from this directory as the source for PandaLogica projects. Pin references to an approved repository commit, as described in the [repository README](../README.md). Request a reviewed variant if a different background, aspect ratio, or resolution is needed; do not silently alter the official file.
